# Security policy

## Supported versions

We fix security problems in the latest released version of `@focus-reactive/payload-plugin-content-agent`.

## Report a problem

Do not open a public issue for a security problem.

Send the report through the [contact form](https://focusreactive.com/#contacts) on our site. Write in the message that it is about a security problem in the Payload content agent plugin.

Include in the report:

- The version of the plugin, of Payload and of Node.js.
- The steps that show the problem.
- What an attacker can do with it.

We reply through the contact details that you give in the form.
